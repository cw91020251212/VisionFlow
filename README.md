# VisionFlow

VisionFlow 是**純前端外觀參考編輯器**。你可以匯入 HTML、調整界面外觀，再匯出給 AI／開發者整合的外觀檔案。它不會自動修改原始工程，不內建 AI 源碼整合，不保證被匯入程式的業務功能。

線上入口：[GitHub Pages](https://cw91020251212.github.io/VisionFlow/)。2026-10-14正式整合版包含四批修復及背景貼圖，由累積PR #5合併至main；分批修復分支與歷史仍保留。GitHub Pages以main部署，提交原始碼和部署成功是不同階段，實際結果見本次發布紀錄。下載main後也可直接開啟 `index.html`；正常使用不需要Node、構建流程或後端。`appearance.js`、`folder-import.js`、`canvas.js`、`project-io.js`、`workspace-state.js`、`pointer-tools.js`、`delivery.js`、`background-image.js`需與HTML放在一起。若舊分頁仍使用舊版，先匯出重要設計、關閉所有VisionFlow分頁後重新開啟；不要直接清除網站資料，以免刪除本機草稿。

## 使用方式

1. 點左上「☰」開啟專案面板，匯入原始 HTML 或網站資料夾。資料夾有多個 HTML 時可選擇入口，每次只編輯一頁；有未匯出修改時必須先匯出，成功後可切換，切回會保留先前修改。之後再修改要重新匯出。
2. 點「⚙」顯示屬性面板，使用畫布拖動、縮放、屬性欄位、圖層、群組、參考線、吸附、桌面／手機視口和撤銷／重做。
3. 在專案面板補充原工程名稱、頁面路徑及整合說明。切換 Default、Hover、Focus、Disabled 或 Loading 外觀狀態。編輯器模擬所選狀態；匯出的預覽按真正的 CSS 偽類／狀態屬性顯示。
4. 如果元素沒有穩定 ID／data 屬性，填寫名稱／父級區域。欲套用同類組件，先填 CSS selector，再選「所有匹配元素」；位移只支援「僅此元素」，不會覆蓋其他实例的原位移。
5. 點「匯出外觀 HTML」下載可重新匯入的外觀預覽；點「匯出 JSON」下載机器可讀的修改資料。**不要用外觀 HTML 取代原工程。**

文字、連結、表單名稱與類型、圖片來源、事件、資料邏輯及程序狀態預設受保護。匯入模式不能新增演示圖形；新增圖形仍可在空白演示畫布使用。主題配置只調整編輯器／演示畫布，不任意改寫匯入頁面背景。

### 資源報告、分享與離線（第四批）

匯入頁面後，左側「本頁資源報告」列出未內嵌的 HTTP／HTTPS 資源、外部 base、遠端 CSS／字體／圖片／srcset 和腳本地址。可展開查看或複製完整報告，警告與目前來源成對保存；切頁或恢復不混用別頁報告。匯入處理器只讀本地檔案，不主動下載遠端；**瀏覽器渲染預覽時仍可能請求列出的網址**。停用腳本的遠端 script 地址只表示原來源／可信預覽的可能依賴，不表示靜態匯出會包含業務腳本。未掃描 JS 動態請求或遠端 stylesheet 內部，因此「0 項依賴」不代表保證全離線。

工具列「分享」提供目前畫布／外觀的 HTML 或 JSON。先選格式，再點「系統分享檔案」選擇接收者；分享的是可能包含頁面文字、圖片及說明的檔案，請只交給信任的人。瀏覽器或接收程式不支援該 MIME（JSON 常不支援）、權限被拒絕或分享失敗時，可用「下載檔案」自行傳送。取消不會標記已匯出。系統接受分享不等於接收者已收到；請自行確認。**複製編輯器網址不包含設計**；本版未把設計上傳雲端，也不提供公開設計短連結。

支援的已安裝 PWA 可用系統分享目標接收標題、文字及網址（GET，非檔案接收）。內容先顯示，明確按「加入本頁交接說明」才修改；不抓取網址、不執行文字、不把網址當作匯入原網站。空白畫布說明最多10000字元，匯入頁面說明最多100000字元。快捷入口使用相對子路徑，「新建」／「匯入」只打開專案面板，不清空既有草稿。

HTTPS 或 localhost 下，頁腳會顯示應用離線快取狀態；成套快取只包含編輯器本身，不包含使用者設計、匯入工程或遠端資源。首次完整建立後可離線重新開啟；草稿仍來自該瀏覽器 localStorage，容量及瀏覽器清理限制不變。新版本等待使用者按「保存並更新」，保存失敗或手勢未完成時不刷新；有其他同 scope 編輯器分頁時先要求關閉，避免舊程式／新檔案混用。沒有自動刷新其他分頁。file:// 仍可匯入、編輯、下載，但不註冊此 Service Worker。

### 暫存／更新／出廠還原

頁腳的 **「暫存／更新／還原」** 開啟維護面板，顯示目前程式版本。「檢查更新」可手動檢查，並不刪除或刷新設計；新版套件完整下載後，才顯示「保存並更新」。更新不是把程式退回舊版。

**清除暫存並重新載入** 先安全保存目前設計，清除本 VisionFlow 的離線程式快取和記憶體暫態，取消本 scope 的離線註冊，再重新開啟。保留設計草稿及升級備份；保存失敗會拒絕重新載入。這不是清空整個瀏覽器的 HTTP 快取，也不清其他 GitHub Pages 網站的存儲或服務工作者。

清快取及套用更新都必須等待正在處理的HTML／資料夾／JSON匯入、iframe載入或貼圖讀取完成；不會把它當作「可以丟掉的暫存」悄悄取消。明確取消輸入後可重試；出廠還原則在不可撤銷確認後可以放棄尚未完成的输入。套用更新或清理導航已開始時，不再接收新匯入／貼圖，會提示完成後重新選擇。

**還原出廠狀態** 是另一個需要確認的操作：刪除已保存的 VisionFlow 草稿、升級前備份及其中的工具設定，放棄目前未匯出的設計，重新開始空白預設，不能撤銷。面板提供「先下載草稿備份」；重要設計請另外下載 HTML／JSON。原始 HTML、圖片檔及其他網站資料不改；未知／損壞草稿也可由這個明確的還原操作清除。清理前必須先關閉其他 VisionFlow 分頁／桌面 App，清理中不要另開分頁；有可用服務工作者時會檢查並拒絕多分頁清理。網路不可用時不刪除離線快取；file:// 沒有應用快取／線上更新，仍可明確還原本機草稿。

小屏工具列可左右滑動；只是改善提示和對話框焦點，不表示已完成全面手機操作優化。新版 `resources` 是外觀 JSON／Draft v2 的可選欄位，舊檔繼續可讀。仍需保留每頁 HTML／JSON 及重要草稿的獨立備份。

### 工作區、全屏與量尺

左右欄開關、關閉面板及全屏往返只刷新布局，不會改掉手動縮放。全屏記住進入前四種面板組合，退出／原生 Esc 事件恢复原組合。瀏覽器拒絕原生全屏時改用專注檢視，「退出」按鈕仍可用；不把原生全屏權限當成草稿持久化。

「適配」按鈕、新來源載入與明確切換桌面／手機視口會調整縮放；恢復草稿／撤銷／切回已保存頁不自動適配。新的手動縮放會取消舊 iframe 延遲載入的適配，舊載入回呼不能套用到另一个來源。

量尺完成第二次點擊後保持尺寸。關閉量尺按鈕只關閉新的量度操作，已完成結果仍显示並可暫存／恢復；再次開啟量尺開始新量度，切入平移則取消量尺結果。量度只保存已完成結果，進行中未完成的量度在刷新／撤銷恢复時安全取消，不會出現幽靈終點。第三批已接通父畫布與同源 iframe 的工具事件，量尺及參考線以原頁面像素計算，補償畫布縮放和 iframe 內部滾動；按 Alt 暫停吸附。

### 多選、框選與工具取消（第三批）

普通畫布與匯入頁均可按 **Ctrl／⌘ 點選**來加入或再次移除圖層。群組成員作為同一選取單位；點已選圖層拖動維持整組選取，不會由其後 click 抵消。左側圖層列表使用相同增減規則。

拖動空白处或开启工具列的 **▧ 矩形框選**，完整包住目标图层后放开。Ctrl／⌘ 框选追加；空框清空选择，Escape 取消不提交。框选包括被遮挡的图层和容器内的子元素，使用文档中可见候选图层，不受最上层点击命中限制；最多1000个。右侧列表显示所有选中项目，点某一项可编辑单件。

多选面板的背景、文字颜色／大小／字体、圆角、边框粗细／颜色和投影可批量套用，**只改动操作的字段**；混合值不自动统一。复杂渐层与尺寸请先在选中列表点选单件。若存在「所有匹配元素」范围记录，批量修改会拒绝并要求先改回「仅此元素」，避免影响未选中的内容。导入文字、链接与业务继续受保护。

多选仅支持整体移动，不提供八向群组缩放，也不再只缩放第一项；单件保留原九个手柄。选中父与子时，整体移动只对独立根元素写位移，子元素随父元素移动一次，不叠加双重 translate。锁定位置依然禁止整体移动。

平移／量尺／擦胶／框选工具互斥，优先接收画布事件，不会顺带拖动内容或触发按钮。擦胶按住扫过参考线，按移动路径一次删除多条，整个手势可一次撤销。Escape、pointercancel、失去捕获、窗口失焦或切换工具会结束手势，并回到该手势前的设计；取消参考线复制也不会留下复制品。自动暂存不会写入未完成手势。

## 匯出格式

| 檔案 | 內容 | 用途 |
| --- | --- | --- |
| `visionflow-appearance.html` | 靜態外觀、需要的外觀 CSS，以及 `script[type="application/json"]#visionflow-appearance-data` | 視覺對照、重新匯入繼續編輯；不含可執行業務脚本 |
| `visionflow-appearance.json` | `format: visionflow-appearance-v1`、來源、頁面、視口、修改、保留事項與補充說明 | AI／開發者按明确修改整合原工程 |
| `visionflow-canvas.html` | 空白畫布的圖形／文字及內嵌 `visionflow-canvas-v1` JSON | 純表面設計、可回讀；不帶工具層或可執行腳本 |
| `visionflow-canvas.json` | 畫布視口、主題背景、位置、尺寸、群組及圖層樣式 | 重新編輯畫布或交給 AI；不是原程式的 selector 修改檔 |
| `visionflow-draft-backup.json` | 本機草稿的原始位元內容 | 復原排錯用；不是日常匯入的畫布／外觀 JSON |

不匯入原網頁時，可從「新增圖形」建立空白設計。兩個匯出按鈕會自動顯示「匯出畫布」，HTML 與 JSON 均可透過原匯入入口重新開啟。畫布視口是固定 1280×720 或 375×812，不自動產生響應式布局；最多 1000 個圖層，JSON 上限 25 MB。

只有明確修改過的 CSS 屬性會進入 `changes[].styles`。每項修改包含 `target`、`page`、`viewport`、`state`、`scope` 與 `preserve`。版本格式可表示多頁修改；本版界面一次編輯一頁，請為各頁保留獨立檔案。來源 SHA-256 為原始入口 HTML 的校驗值，不是整个仓库或内联資源後 HTML 的版本校驗值。

桌面編輯尺寸為 1280×720，手機為 375×812；匯出採用 700px 分界的 media query，後續整合 AI 應改用原工程的響應式斷點。Hover／Focus 使用 `:hover`／`:focus`，Disabled 使用 `:disabled` 或 `aria-disabled="true"`，Loading 使用 `aria-busy="true"` 或 `data-state="loading"`。原工程有不同狀態命名時需由整合者對應。

位移使用 CSS `translate` 保留原 `transform`，並附上父級、相鄰元素、間距、參考矩形和 `preserveResponsiveLayout` 的布局意圖。這些像素是視覺參考，不表示應把原工程改為絕對定位。

匯入獨立外觀 JSON 前須先載入相符的原始 HTML。新版額外保存 `origin={entryPath,sourceHash,schemaVersion:1}` 和可編輯的 `integrationPagePath`；來源入口或校驗值不符仍拒絕，但填寫 `/login` 等整合路徑不會誤判為換了來源。舊 `visionflow-appearance-v1` 檔案由 `source.htmlFile/sourceHash` 讀取來源識別。沒有校驗值的舊檔只能依入口識別，不能保證檔案內容相同。匯入外觀 HTML 時可直接恢復其內嵌修改資料。

## 保存和脚本預覽

外觀修改約350ms後自動存到**目前瀏覽器的 localStorage**，「暫存」可立即保存。草稿包含原始來源、內嵌資源後的來源、可序列化外觀模型、選取識別、群組、參考線、視口、主題和工具狀態，並另存靜態視覺快照。刷新會恢復草稿而不執行原脚本。容量不足或權限不允許會提示，請匯出備份；清除瀏覽器資料、私密模式或改用另一裝置不保證保留草稿。

第二批寫入 Draft v2，讀取仍支援 v1 並沿用 `visionflow-appearance-draft-v1` key，不要求清空草稿。新版本保存鎖點總開關／網格／滑鼠鎖點預覽、正常面板組合及量尺 enabled/state/start/end；舊 v1 缺少三偏好時使用「鎖點開、網格開、滑鼠預覽關」，缺端點的舊量度不能重建，只恢復量尺模式且不捏造結果。新資料先校驗才恢復，操作模式互斥，非法座標或不一致的工具狀態仍保護原草稿。

第一次將現有 v1 升級為 v2 前，原文字原樣存到 `visionflow-appearance-draft-v1-backup-before-v2`，只建立一次，不覆寫舊備份。左側專案面板的「下載升級前草稿」可下載它；沒有舊備份時按鈕停用。若備份因容量不足無法建立，原 v1 不會被 v2 替換，需先下載外觀或草稿備份。多個同源舊版本分頁的並行存檔未提供完整衝突合併，請關閉舊編輯器分頁再使用修復版。

多入口修改保存於同一草稿的逐頁工作集合，刷新會先恢复目前靜態頁。原本的 `File` 物件只留在記憶體，不寫入 localStorage；要重新切頁需重選原資料夾。重選相符原入口後會恢復已保存的各頁修改。各頁仍需分別匯出，未提供「整個網站一鍵匯出」。容量限制可能使大工程無法暫存，應另行下載每頁檔案。

「備份草稿」下載目前 localStorage 的原始資料，不清除或覆寫它。遇到未知版本或無法恢復的草稿會停止自動覆寫，請先下載備份，再用另一個瀏覽器工作區開啟新專案；不提供損壞草稿的自動重設。若確認要放棄損壞草稿，現在可在維護面板明確「還原出廠狀態」，不是自動修復或復原備份。第三批補上多選、平移／量尺 iframe 事件、參考線坐標與連續擦膠。尚未提供 Safari／Firefox／真實手機全套驗收，第四批已接通應用離線快取與安全檔案分享，但複雜工程和真實裝置驗收仍需後續處理，不能視為全軟件已無問題。

匯入脚本**預設停用**。如果要觀察自己程式的 JS 生成元素或事件，可勾選「允許可信頁面的脚本預覽」。這不是安全隔離：可信脚本可存取網路及同源編輯器。不要對不可信 HTML 開啟。信任選項不會跨刷新保存，執行時事件、資料請求及狀態不能變成可還原的原工程。匯出會刪除全部原有 script，包括 hydration／業務 JSON，只追加 VisionFlow 自己的非執行外觀 JSON。

## 明確限制

| 範圍 | 限制 |
| --- | --- |
| 網站資料夾 | 處理目前入口的本地 CSS、遞迴 `@import`、圖片、字體及傳統 JS 資源；使用可保存的 data URL，不用暫時 blob URL。不是完整網站／SPA 導入器。 |
| 外部資源 | HTTP 資源依賴網路，並非全離線。`fetch()`、動態 import、模組解析、伺服器路由與建置產物不保證可運作。缺少本地資源會列明原因。 |
| `srcset` | 本地 `srcset` 暫不轉換，会顯示警告；不保證相應響應式圖片可離線重現。 |
| CSS 編輯 | 單一 linear-gradient 可調角度與起止色並保留其他 stops。複雜／多層／radial 背景不做局部解析，需明確關閉再啟用來替換。陰影參數調整保留其他參數、spread／inset 及其他陰影。 |
| 尺寸與移動 | 尺寸保留原 box-sizing；寬高修改或自由位移可能仍影響內容換行、溢出和響應式，整合者必須檢查。沒有自動 Flex／Grid 重構。 |
| 狀態與元素 | 偽元素、跨來源 iframe、Shadow DOM 內部不保證可編輯。最多列出 1000 個可見候選圖層；結構路徑仍可能因工程版本變更失效。 |
| 裝置相容 | 自動測試使用 Chromium；未完成 Safari、Firefox 和真實手機全套測試。需要支援 CSS translate 的現代瀏覽器。 |

## 開發與測試

測試工具僅供開發，不是產品的執行依賴：

```sh
npm ci
npx playwright install chromium
npm run check
npm test
```

需有 Python 3 供測試啟動本地靜態伺服器。測試涵蓋普通按鈕、原有漸層／陰影卡片、輸入框、連結、重複列表、手機換行與 JS 生成元素，另有資料夾、直接 file:// 開啟、复杂样式、來源切換、刷新、重新匯入、JSON、脚本排除及原事件保護。

維護 PWA 時，每次修改應用檔案須同步更新 `sw.js` 的 `APP_VERSION`、HTML的`visionflow-app-version`及全部JS的`?v=`參數，並將新增啟動資源加入 `APP_FILES`；版本字串不可重用，避免取消SW後仍命中舊HTTP脚本。完整套件先安裝成功才更新，缺檔不擾動前版。`window.history` 是瀏覽器 History API；全局 `history` 是編輯器撤銷陣列，勿混用。這個修復副本沒有獨立的 Manus 專案診斷綁定，採用既有 `npm run check` 及 Playwright，而非借用 FormLab 的 TypeScript 診斷。`maintenanceStoragePaused`只在資料清理／導航階段阻止保存，不能把出廠刪除的舊資料在pagehide寫回。

原生分享能力依據：[MDN Navigator.share](https://developer.mozilla.org/en-US/docs/Web/API/Navigator/share)。離線更新生命週期：[MDN Using Service Workers](https://developer.mozilla.org/en-US/docs/Web/API/Service_Worker_API/Using_Service_Workers)。Chromium 回歸使用原生 Service Worker；分享接收者用 API 替身測試，不等於 Windows／Android 分享面板的完整人工驗收。

## 背景貼圖（正式整合版）

本次正式整合版包括背景貼圖及四批修復；`feat/background-textures`分支保留作開發紀錄。新增啟動檔案 `background-image.js`必須與其他JavaScript放在`index.html`旁。

先在畫布選取大標題的背景容器（不要只選其中的文字子層），打開右側屬性面板，使用 **背景貼圖 → 上傳／更換圖片**。普通畫布的單件圖形與文字框也支援。可選 Cover 填滿、Contain 完整顯示，或自訂圖片寬度10–400%；以水平／垂直位置滑桿選裁切重心，再選不重複、橫直重複或單方向重複。位置0%對齊左／上，50%置中，100%對齊右／下；圖片剛好填滿該軸時，位置改變不會产生位移，这是 CSS 背景的正常行為。紋理可用自訂小比例搭配重複。原來已有 CSS 貼圖也可直接調大小、位置和重複，不需要先上傳。

上傳／更換會取代目前的圖片或漸層；「開啟漸層」也明示會取代貼圖，均可撤銷。更改純背景色、位置、邊框、陰影、文字大小不會清掉圖片。「移除貼圖」改成沒有背景圖片；匯入模式的「還原原背景」刪除此視口／狀態的四個背景長寫覆寫，回到原來源或 Default 狀態的背景。多層背景保留原值；尺寸／位置／重複設定會作用所有層，沒有逐層圖片編輯器。

只接收真正的 PNG、JPEG、WebP；不支援 SVG/GIF。檔案最多10MiB、解碼最多12000px長邊及36MP。大圖按原比例縮到2048px，必要時轉成WebP（可能有輕微有損壓縮，保留透明度）；處理後內嵌最多2MiB。這些操作只在瀏覽器本機进行，不改你的原檔、不把照片上傳雲端。過大／壞檔會顯示原因並保留原背景。多張圖會使草稿容量很快增加；存儲不足時請直接下載 HTML／JSON，不依賴自動暫存。

貼圖與參數會寫入 HTML／JSON及本機草稿，重新匯入仍可編輯；不用帶暫時 blob URL或原圖片檔。原有遠端背景未內嵌時仍需網路。新檔保持v1格式並增加可選背景欄位；新版本能讀舊無贴图檔，舊軟體版本不保證能讀新增的圖片CSS，請使用增補版回讀。

**這是背景貼圖功能，不是Photoshop修圖。** 不修改圖內的文字、圖片像素、前景 `<img src>` 或偽元素 `::before/::after`。背景上的真實HTML標題文字保留，可繼續調字體、字色、大小。文字如果已烘焙在圖片裡，需要另外製作圖片再換入。多選時先在選中列表選取單件；本版不批量替換所有圖片。
