# VisionFlow

VisionFlow 是一個專業的網頁視覺設計工具，旨在提供直觀且強大的介面，讓設計師和開發者能夠輕鬆創建和編輯網頁佈局。

## 主要功能

- **直觀的畫布操作**：支持拖拽、縮放和即時預覽。
- **多端適配預覽**：一鍵切換桌面與手機視圖。
- **AI 輔助設計**：內建 AI 助手，協助生成設計方案和代碼。
- **靈活的圖層管理**：輕鬆管理複雜的設計元素。
- **專業參考線系統**：支持垂直與水平參考線，確保設計精確。
- **檔案分享與導出**：支持導出為 HTML 或 JSON 專案檔案，並新增了原生分享功能。

## 如何使用

1. 下載本倉庫的所有檔案。
2. 直接在瀏覽器中打開 `index.html` 即可開始設計。
3. 您可以使用「匯入 HTML」功能來編輯現有的網頁。
